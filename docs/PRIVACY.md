# 隐私说明

本说明针对本仓库提供的应用实现。自行修改或配置代理后，数据接收方可能不同。

- **本地数据**：收藏、关注艺人、应援色、设置和搜索缓存保存在设备 / 浏览器的本地存储中。应用没有项目账号系统或项目提供的云同步。
- **搜索**：查询艺人或打开详情会连接相应票务平台。对方可以接收查询词、IP 地址和请求信息，并按其自己的政策处理。
- **可选代理**：构建时配置代理后，代理也会接收查询。官方公开 APK 默认直连，不附带维护者的私人代理地址。
- **图片与外部链接**：显示远程图片会请求对应图片服务；打开购票链接后由系统浏览器或目标应用处理。
- **通知**：提醒由系统在本机调度，需要用户授权；系统省电、通知和闹钟设置可能影响到达时间。
- **日历导出**：用户主动导出时生成 `.ics` 文件，交给系统日历或分享目标处理。iOS 当前不提供该导出入口。
- **删除与备份**：清除应用数据、清除浏览器站点数据或卸载可能删除本地记录。系统级备份与恢复取决于操作系统及用户设置；Android 工程允许系统备份。

报告问题时请勿上传私人记录、账号凭据、Cookie 或签名文件。应用不替代票务平台的隐私政策。
