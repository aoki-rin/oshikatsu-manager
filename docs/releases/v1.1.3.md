# 推し活マネージャー v1.1.3

修复实机审查发现的场次丢失、收藏串场、日历时间不准确及票务详情获取失败无提示等问题。

## 更新内容

- 同日同馆的不同演出分别显示，收藏和开演提醒按具体场次独立处理；旧缓存重新搜索后可恢复可辨认的场次。
- eplus 使用完整公演身份生成编号，修复同日不同公演在去重时被丢弃的问题。
- 日历导出保留各轮申请、结果公布及入金节点的精确时间，不再把真实截止时间统一改为 23:59；未知开演时间导出为全天待定日程。
- Lawson 按官网明确列出的日期拆分多日公演，未知时间不再显示为午夜或生成午夜开演提醒。
- Pia 官网繁忙或详情无法完整获取时显示提示，保留已有资料，允许手动重试。
- 兼容旧收藏、缓存和提醒编号；禁用聚合卡片的主要来源后，其他已启用来源仍可显示。
- 设置页版本号与应用版本同步；Android / iOS 统一为 1.1.3，原生构建号为 5。

## 下载与升级

Android 下载 `oshikatsu-manager.apk`，沿用原有正式签名，可覆盖更新。`SHA256SUMS` 用于校验 APK 和第三方许可证文件。源码可通过本页的 Source code ZIP / tar.gz 下载；运行和构建步骤见 [README](https://github.com/aoki-rin/oshikatsu-manager#readme)。

iOS 提供源码和 [Xcode 构建安装教程](https://github.com/aoki-rin/oshikatsu-manager/blob/v1.1.3/docs/BUILDING.md#ios)，当前没有 TestFlight 或通用可直接安装的 IPA。

## 验证范围

- 363 项单元/组件测试、6 项浏览器流程测试及 TypeScript 检查通过；发布流程再次执行版本、依赖审计、覆盖率和构建检查。
- 使用此前 Pixel / iPhone 获取的原始响应重放：eplus 20 条均保留独立编号，LivePocket 不同场次分开，Lawson 两个公演日分别保留，日历保留真实 18:00 截止时间。
- 修复代码已在 Pixel 和 iPhone 完成安装与启动检查；Android 正式签名包、iOS 真机和模拟器构建通过。
- 修复后的完整实时抓取、收藏操作和系统通知送达尚未重新做双机验收。原始响应重放与自动化测试不能代表所有平台页面或设备状态。

修复和迁移细节见 [实机问题修复记录](https://github.com/aoki-rin/oshikatsu-manager/blob/v1.1.3/docs/reviews/2026-09-13-device-live/FIXES.md)。

## 已知限制

- 票务网站改版、繁忙或网络策略可能影响结果，请以官网信息为准。
- 旧缓存已丢失的完整场次不能凭空恢复，需要重新搜索获取；来源信息不完整时保守保留旧记录。
- 最低 Android 7.0；Lawson 搜索在无 Google Play Services 设备上的兼容性尚未验证。
- 收藏和设置保存在本机，卸载或清除应用数据可能丢失记录。
