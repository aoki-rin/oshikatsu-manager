# 推し活マネージャー v1.1.2

首个公开源码与 Android APK 发行版。可搜索日本 Live 票务、收藏演出、关注艺人并设置本地受付提醒。

## 此版本

- 使用 MIT 许可证开放原创代码，补充运行、构建、隐私和贡献说明。
- 发布包默认手机直连，不包含维护者私人代理配置。
- Android APK 沿用原有签名；版本号统一为 1.1.2，原生构建号为 4。
- 增加版本校验、签名验证和自动生成 Release 草稿的发布流程。
- 更新存在安全公告的依赖，用直接 Sharp 依赖替代旧图标工具链；本次依赖审计无已知漏洞。

## 下载

Android 用户下载 `oshikatsu-manager.apk`；`SHA256SUMS` 用于校验下载内容。源代码可通过下方 GitHub 自动生成的 ZIP / tar.gz 下载。

## 发布验证

- 干净目录安装依赖、TypeScript 检查、339 项自动测试及 6 条浏览器关键流程通过。
- Android 调试包和正式签名包构建通过；本地正式包签名与上一版本一致。
- iOS 模拟器构建通过。
- 发布构建已验证不继承本地 `.env` 或终端中的私人代理地址；缺少签名配置和错误版本标签会被拒绝。

## 已知限制

- 最低 Android 7.0；Lawson 搜索的无 Google Play Services 设备兼容性尚未验证。
- iOS 当前仅提供源码自行签名构建教程，没有 TestFlight 或通用可直接安装 IPA。
- 票务网站改版、限流或网络策略可能影响搜索，受付信息以官方页面为准。
- 自动测试不代表所有手机、通知权限状态和真实票务平台均已验证。
- 收藏和设置保存在本机，卸载或清除应用数据可能丢失记录。
